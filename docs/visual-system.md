# HERMES Visual System

HERMES uses a deep midnight-navy foundation with electric teal for active pathways and warm gold for trust, value, and approval gates. The visual language combines messenger symbolism with precise systems diagrams.

| Token | Hex | Use |
|---|---|---|
| Midnight | `#06132B` | README backgrounds, banners, diagrams |
| Navy | `#0B1F3A` | Core nodes and panels |
| Electric teal | `#20E0D0` | Active flow, links, success states |
| Warm gold | `#D6A63A` | Brand mark, value, approvals, highlights |
| White | `#FFFFFF` | Primary text on dark backgrounds |

The repository logo is intentionally symbol-only so it scales to avatars, favicons, documentation headers, and product UI. The banner leaves quiet space on the left for GitHub title text and places the orchestration network on the right. The framework infographic is conceptual; the Mermaid sources remain authoritative for exact relationships.

## Asset usage

- `assets/hermes-logo.png`: repository avatar and documentation mark.
- `assets/hermes-banner.png`: hero banner and social preview candidate.
- `assets/hermes-framework.png`: conceptual HERMES layer visual.
- `docs/rendered/workflow-map.png`: exact workflow map export.
- `docs/rendered/agent-topology.png`: exact agent topology export.

Generated visual assets should remain free of sensitive customer information, unsupported claims, and third-party marks.
